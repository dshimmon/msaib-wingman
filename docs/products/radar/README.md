# Portfolio Wingman/Radar

Portfolio Wingman and Radar are the same approved future product, expressed as
Portfolio Wingman/Radar. It is separate from Atlas and Wingman OS core. This
namespace establishes physical ownership only; it contains no production
behavior, registry entry, schema, workflow, or feature implementation.

Any future Portfolio Wingman/Radar mission must attach through Product Contract
v1 or a separately approved later contract, preserve source traceability and
human oversight, and keep financial policy outside Wingman Core and Shared.

See the [attachment boundary](attachment.md),
[ARCH-002](../../decisions/architecture/product-separation.md), and the approved
future-product entry in `WINGMAN_VAULT.md`.
