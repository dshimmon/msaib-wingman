# Current Knowledge Flow

Wingman preserves a path from every answer back to source evidence:

```text
source file or registered source
  -> neutral document units with physical locations
  -> source-identified knowledge objects
  -> deterministic concepts, records, and embeddings
  -> product interpretation creates a neutral retrieval plan
  -> Core retrieval and evidence ranking
  -> source enrichment restores metadata and original paths
  -> product response or briefing with traceable evidence
```

Atlas supplies academic enrichment and query interpretation at the product
boundary. Core owns extraction, storage, indexing, and neutral retrieval.
Conversation context may guide interpretation but never replaces fresh
retrieval from authorized sources.

[ARCH-003](../decisions/architecture/source-traceability.md) is the official
decision and controls if this summary conflicts.
