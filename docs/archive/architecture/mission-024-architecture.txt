DETERMINISTIC CONFIDENCE GATE
============================================================

Deterministic Text Evidence
        |
        v
Evidence Ranking
        |
        v
Confidence Evaluation
        |
        +-- Score below 3?
        |         |
        |         +-- YES --> Semantic retrieval
        |
        +-- Multiple search terms?
                  |
                  +-- Specific phrase matched?
                  |
                  +-- Multiple terms matched?
                  |
                  +-- NO --> Semantic retrieval
                  |
                  +-- YES --> Keep deterministic evidence


Purpose:

Prevent a broad search term from blocking a stronger
meaning-based result.

Example:

Question:
What kind of computer do I need for the program?

Broad deterministic match:
MSAIB Curriculum

Correct semantic match:
Laptop Recommendations

============================================================
CONVERSATION GUARDRAILS
============================================================

Conversation history may be used to understand:

- Pronouns
- References
- Omitted subjects
- Follow-up scope
- Which prior entities the user means


Conversation history may not be used as:

- Supporting evidence
- A replacement for retrieval
- Proof that a prior answer was correct
- Permission to accept a false premise
- Authority over the current question


Core rule:

Conversation provides context.
Sources provide truth.


Every conversational turn must still produce:

Current Question
        |
        v
Fresh Retrieval Plan
        |
        v
Fresh Wingman Evidence
        |
        v
Grounded Answer

RESPONSIBILITY BOUNDARY
=======================

OPENAI

* Interprets natural-language questions
* Produces structured retrieval instructions
* Creates numerical embeddings
* Reasons over organized context
* Produces the final answer

WINGMAN OS

* Creates structured knowledge
* Preserves metadata and sources
* Stores concepts and records
* Maintains persistent concept memory
* Creates and stores knowledge embeddings
* Executes retrieval plans deterministically
* Performs exact record filtering
* Compares semantic similarity
* Rejects weak semantic matches
* Ranks evidence
* Builds context for OpenAI

MISSION 024 OUTCOME
============================================================

Before Mission 024:

Atlas displayed previous conversation turns, but every new
question was interpreted independently.

References such as "those," "that course," or "which of
them" had no backend meaning.

Atlas uses recent source-grounded conversation context to
interpret follow-up questions while requiring fresh
evidence for every answer.
