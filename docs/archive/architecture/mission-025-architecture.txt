============================================================
CONVERSATION GUARDRAILS
=======================

Conversation history may be used to understand:

* Pronouns
* References
* Omitted subjects
* Follow-up scope
* Which prior entities the user means

Conversation history may not be used as:

* Supporting evidence
* A replacement for retrieval
* Proof that a prior answer was correct
* Permission to accept a false premise
* Authority over the current question

Core rule:

Conversation provides context.
Sources provide truth.

Every conversational turn must still produce:

Current Question
|
v
Fresh Retrieval Plan
|
v
Fresh Wingman Evidence
|
v
Grounded Answer

RESPONSIBILITY BOUNDARY
=======================

OPENAI

* Interprets natural-language questions
* Produces structured retrieval instructions
* Creates numerical embeddings
* Reasons over organized context
* Produces the final answer
* Creates structured retrieval plans for general briefing requests
* Converts supplied briefing evidence into verified facts
* Proposes clearly labeled recommended actions
* Identifies meaningful open questions

WINGMAN OS

* Creates structured knowledge
* Preserves metadata and sources
* Stores concepts and records
* Maintains persistent concept memory
* Creates and stores knowledge embeddings
* Executes retrieval plans deterministically
* Performs exact record filtering
* Compares semantic similarity
* Rejects weak semantic matches
* Ranks evidence
* Builds context for OpenAI
* Detects recognized academic module briefing requests
* Creates deterministic module briefing plans
* Executes focused briefing retrievals
* Limits evidence by briefing category
* Deduplicates briefing evidence
* Assigns stable evidence references
* Restricts generated citations to supplied evidence
* Preserves complete briefing source traceback
* Renders verified facts, recommended actions, and open questions separately

============================================================
MISSION 025 PRINCIPLE
=====================

Sources establish the situation. Atlas proposes the action.

Sources establish:

* Verified facts
* Curriculum records
* Schedule records
* Dates
* Documented preparation
* Technology requirements
* Exact provenance

Atlas proposes:

* Retrieval planning
* Evidence selection
* Recommended actions
* Prioritization
* Open questions

The source remains authoritative for what is true.

Atlas remains responsible for interpreting that verified
situation and proposing what the user should do next.

============================================================
MISSION 025 OUTCOME
===================

Before Mission 025:

Atlas could answer direct, source-grounded academic
questions.

A broad preparation request still depended on the user
asking several separate questions and assembling the
answers manually.

After Mission 025:

Atlas can convert a broad study-preparation request into:

* A focused evidence plan
* Verified source facts
* Clearly labeled recommended actions
* Meaningful open questions
* Traceable supporting evidence

The existing Chat pipeline remains responsible for:

* Direct questions
* Grounded answers
* Conversational follow-ups

The Briefing pipeline is responsible for:

* Multi-category preparation requests
* Deterministic module evidence plans
* Evidence selection and deduplication
* Structured action-oriented briefings
