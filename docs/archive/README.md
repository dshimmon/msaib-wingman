# Documentation Archive

Everything below this directory is noncanonical historical evidence:
superseded architecture snapshots, retired planning, or former working notes.
Files are preserved for provenance and may contain status, paths, commands, or
decisions that were accurate only at the recorded time.

Current authority lives in `docs/missions/` and `docs/decisions/`. Current
architecture lives in `docs/wingman-os/` and `docs/products/`. Archived wording
must never override those homes.
